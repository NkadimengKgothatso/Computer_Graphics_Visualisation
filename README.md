## 🛠️ Building & Running

Labs and projects use **OpenGL**. General usage per lab/project (adjust as needed once build files exist):

```bash
cd labs/lab1
make
./run
```

## ⚙️ Requirements

- C/C++ compiler (GCC/Clang) or as specified per lab
- OpenGL development libraries (e.g. `freeglut3-dev`, `libglew-dev` on Linux)
- `make`
